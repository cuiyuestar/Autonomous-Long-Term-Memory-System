## 2026-06-30 - 第一批最小安全修复

修改文件：

- `src/altm/storage/sqlite_store.py`
- `src/altm/retrieval/fts.py`
- `tests/test_review_queue.py`
- `tests/test_review_actions.py`
- `tests/test_embeddings.py`
- `tests/test_sqlite_schema.py`

修复内容：

1. 将 `put_memory_unit()` 的底层写入抽成同连接 helper，保持公共方法行为不变。
2. 将 `put_l2_atom()` 的 MemoryUnit 写入和 typed table 写入放入同一 SQLite transaction。
3. `update_l2_review_status()` 现在要求 L2 MemoryUnit 具备合法 `atom_type`，并要求对应 typed row 存在；缺失时抛错并回滚，不写审计事件。
4. `put_memory_unit()` 始终替换 evidence refs，空列表会清理旧证据链。
5. 远程 embedding 通道失败后，召回候选会携带 `remote_vector_degraded`，并在 explanation 中说明 fallback retrieval channels 被使用。


验证结果：

- 局部测试：12 tests 通过。
- 全量测试：54 tests 通过。
- compileall：通过。

剩余风险：

1. CLI/MCP 入口重复编排仍存在，需下一阶段决定是否抽应用服务层。
2. TypeScript contracts 仍滞后，需下一阶段决定采用生成链路还是 drift check。
